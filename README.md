# 🎭 Emotion Detector

A text emotion classifier (TF-IDF + Logistic Regression) wrapped in a
polished Streamlit app, with single-sentence prediction and batch CSV
prediction.

## Project structure

```
emotion-detection-app/
├── data/train.txt          # training data (text;emotion, semicolon-separated, no header)
├── src/
│   ├── preprocessing.py    # reusable text-cleaning functions
│   ├── train.py            # trains + saves vectorizer, model, label map
│   └── predict.py          # loads artifacts, exposes predict(text)
├── models/                 # saved .pkl / .json artifacts (generated by train.py)
├── app.py                  # Streamlit app
├── requirements.txt
└── README.md
```

## ⚠️ About the included data

`data/train.txt` in this repo is a **small demo dataset** (~90 example
sentences across 6 emotions: joy, sadness, anger, fear, love, surprise) so
the app runs end-to-end out of the box. **Replace it with your full
training set** (same `text;emotion` format, no header) for real-world
accuracy — the original notebook this project was built from used a much
larger dataset.

## Setup

```bash
# 1. Create and activate a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Download required NLTK data (only needed once)
python -m nltk.downloader stopwords

# 4. Train the model (reads data/train.txt, writes to models/)
python src/train.py

# 5. Run the app
streamlit run app.py
```

The app will open at `http://localhost:8501`.

## Using your own dataset

1. Replace `data/train.txt` with your file, keeping the same format:
   `sentence text here;emotion_label` — one per line, `;`-separated, no header.
2. Re-run `python src/train.py`. This regenerates:
   - `models/tfidf_vectorizer.pkl`
   - `models/logistic_model.pkl`
   - `models/emotion_number.json` (label map + accuracy)
3. Restart the Streamlit app — it will automatically pick up the new
   classes and colors it doesn't recognize will fall back to a neutral
   style, so update `EMOTION_STYLE` in `app.py` if you add new emotion
   labels.

## Deploying to Streamlit Community Cloud

1. Push this project to a GitHub repo (make sure `models/*.pkl` and
   `models/emotion_number.json` are committed, or add a build step that
   runs `python src/train.py` before the app starts).
2. On [share.streamlit.io](https://share.streamlit.io), point to `app.py`
   as the entry point and `requirements.txt` for dependencies.
3. No hardcoded local paths are used — everything is relative to the
   project root, so it should deploy without changes.

## Features

- Single-sentence prediction with a confidence bar chart across all classes
- Batch prediction: upload a CSV with a `text` column, download results
- Example buttons to try one sentence per emotion
- Session-based history of your last 5 predictions
- Clean, color-coded UI with per-emotion emoji and accent colors
